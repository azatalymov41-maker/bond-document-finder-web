# Техническое задание — Bond Document Finder Web, SEC MVP

## 1. Цель

Веб-сервис для поиска правоустанавливающей эмиссионной документации по облигациям: Indenture, Supplemental Indenture, Prospectus Supplement, Pricing Supplement, Offering Memorandum, Form of Note, Officers' Certificate и др.

**Критичный сценарий:** в документе отсутствует ISIN, но совпадают юридический эмитент, купон, точная дата погашения и связь с материнской компанией, зарегистрированной в SEC.

## 2. Функциональные требования

**FR-01** Поиск одной облигации по ISIN/CUSIP/свободному описанию; поддержка дополнительных полей Issuer, Coupon, Maturity, Currency, CIK, Issue Date.

**FR-02** Парсинг свободного запроса, в том числе `Prologis Euro Finance 4% 05.05.2034 EUR`. Система должна показывать распознанные поля.

**FR-03** Выполнять полнотекстовый поиск SEC по точному идентификатору и параметрам выпуска. Если документ не найден по идентификатору, строить запросы по эмитенту и параметрам.

**FR-04** При наличии CIK получать Submissions API, находить потенциальные filings, извлекать приложения EX-4 и ссылки на документы.

**FR-05** Извлекать текст HTML и некрупных PDF, проверять признаки выпуска. При ошибке HTTP 403/429 отображать статус недоступности.

**FR-06** Классифицировать кандидатов как первичную юридическую документацию, косвенное раскрытие или неустановленный документ. Запрещено считать N-PORT самостоятельным Prospectus.

**FR-07** Возвращать прямой SEC URL, тип, форму, дату подачи, список фактических совпадений, эвристический балл, статус и ошибки.

**FR-08** Массовый поиск по CSV/XLSX, экспорт найденных результатов в XLSX.

**FR-09** Ведётся журнал поисковых запросов, ошибок доступа и проверенных SEC URL.

**FR-10** Пользователь настраивает ограничения количества запросов и проверяемых документов.

## 3. Нефункциональные требования

- Python 3.11+, Streamlit; возможности развернуть с помощью Streamlit Community Cloud или Docker.
- Secure configuration: SEC_USER_AGENT через Streamlit Secrets или локальный `.env`. Нельзя коммитить файлы с секретами.
- SEC Fair Access: именованный User-Agent, ограничение частоты запросов (по умолчанию 0.7 с между запросами), повторные попытки при временных ошибках.
- Отдельные статусы ошибок, отказ от выдуманных ссылок и ложного статуса «найдено».
- Отсутствие доступа к произвольным URL в SEC connector: разрешены только домены SEC.
- Excel-экспорт защищён от формульной инъекции.
- Тестируемые независимые Python-модули.

## 4. Архитектура

`Streamlit UI → Bond Parser → SEC Search Provider → Candidate Resolver → Document Parser → Conservative Matcher → Results/Excel`.

SEC Search Provider использует:
- `https://efts.sec.gov/LATEST/search-index` — полнотекстовая веб-поисковая выдача (недокументированный интерфейс, нестабилен).
- `https://data.sec.gov/submissions/CIK##########.json` — документированный SEC Submissions API.
- `https://www.sec.gov/Archives/edgar/data/...` — URL оригинальных документов.
- `https://www.sec.gov/files/company_tickers.json` — поиск публичной компании, не полный реестр SPV.

## 5. Критерии приёмки

**AC-01** Приложение стартует командой `streamlit run app.py`, без OpenAI API key.

**AC-02** Поисковый запрос по ISIN, распознаваемому CUSIP и эмитенту сформирован корректно.

**AC-03** Для записи, где в Indenture отсутствует ISIN, матчинг опирается на issuer + coupon + exact maturity. Отсутствие прямого ISIN не делает документ автоматически неверным.

**AC-04** SEC N-PORT не классифицируется как Indenture.

**AC-05** Нельзя присваивать статус «verified original document» только на основании поискового индекса; кандидат должен сохранять статус `review`.

**AC-06** Ошибка SEC HTTP 403 не замаскирована сообщением «документация отсутствует».

**AC-07** Excel CSV import/export работает для указанных колонок.

**AC-08** Модульные тесты проходят; сквозной SEC smoke-test выполняется отдельно в окружении с доступом к SEC.

## 6. Известные ограничения MVP

- API поиска SEC Full Text Search нестабилен и может менять структуру ответов.
- Дополнительные страницы истории Submissions filings пока не загружаются автоматически; старые выпуски могут пропускаться.
- Автоматический CIK lookup по списку тикеров не покрывает все SPV; можно вводить CIK материнской компании вручную.
- Для распознавания документов нет OCR и LLM. PDF с текстом поддерживаются ограниченно.
- Размещение Streamlit Community Cloud зависит от доступности SEC с IP хостинга.
- Внешние источники, private document rooms, investor portals, LuxSE, LSE, CNMV и Cbonds пока вне scope.

## 7. Бэклог следующих релизов

**Phase 2**: полный индекс filings, explicit issue window, алиасы эмитентов, определение parent / guarantor, загрузка/кэш подтверждённых документов, точные страницы с доказательствами.

**Phase 3**: международные реестры и официальные сайты, rate-specific provider adapters, готовый HTML/PDF search engine.

**Phase 4**: optional AI verification, структурированные извлечённые купонные условия, изменение ставки, Calls/Puts, амортизация, SLA/monitoring и многопользовательский доступ.
